DIY SPORTS Static Flipbook Website

Deployment:
1. Extract the ZIP file.
2. Upload every file and folder in this directory to your website root.
3. Make sure index.html is configured as the default page.

This website does not require Node.js, a database, or a backend service.
For local viewing, open index.html directly. Some browser sharing features require an HTTP or HTTPS environment.

Controls:
- Click or drag a page corner to turn the page.
- Pages turn automatically every 2.5 seconds by default. Manual navigation switches autoplay off.
- Use the mouse wheel to zoom from 80% to 350%. High-resolution images for the current and upcoming pages preload in the background to keep page turns sharp.
- Hold Ctrl and drag to move the book.
- On phones and tablets, pinch to zoom and use a two-finger drag to move the book. When zoomed in, a one-finger drag also moves the book.
